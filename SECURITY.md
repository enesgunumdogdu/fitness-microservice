# Security

This repository is a public portfolio and learning project. Default credentials and local-only settings in `docker-compose*.yml` and `*-local.yml` files are for development convenience and must not be used in production.

If you discover a vulnerability, please open a [GitHub Security Advisory](https://github.com/enesgunumdogdu/fitness-microservice/security/advisories/new) or contact the repository owner privately. Do not open a public issue for undisclosed security problems.
